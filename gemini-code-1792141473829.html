🎯 Nuestra Misión

En este proyecto explicamos de forma visual, clara y redactada íntegramente con nuestras propias palabras cómo funciona la infraestructura invisible de internet. Queremos resolver la gran duda que surge cada vez que navegamos:

"¿Qué ocurre exactamente desde que escribo una dirección web en mi navegador hasta que mi ordenador encuentra su dirección IP y carga la página?"

A continuación desarrollamos los puntos clave que explican este fascinante recorrido paso a paso.

📚 Las 6 Claves del Viaje DNS

1. ¿Qué es el DNS y para qué sirve?

El DNS (Domain Name System o Sistema de Nombres de Dominio) funciona como la gran guía telefónica de internet. Su función principal es traducir nombres fáciles de recordar para los humanos (como wikipedia.org) a direcciones IP numéricas que entienden los ordenadores y routers (como 198.35.26.96).

2. ¿Por qué usamos nombres y no IPs?

Los ordenadores se comunican exclusivamente mediante números IP (IPv4 como 142.250.184.46 o IPv6). Sin embargo, para los seres humanos recordar secuencias numéricas para cada página web sería prácticamente imposible. Los nombres de dominio nos permiten navegar de forma intuitiva.

3. El recorrido para encontrar la IP

Cuando escribes una URL, el sistema sigue una jerarquía de consultas:

  1. Caché local: El navegador y el sistema operativo revisan si ya la buscaron antes.
  2. Servidor DNS del Proveedor (ISP): Si no está en caché, pregunta a tu operadora.
  3. Servidores Raíz (.): Dirigen al servidor TLD correspondiente.
  4. Servidores TLD (.org, .com): Apuntan al servidor autoritativo del dominio.
  5. Servidor Autoritativo: Da la IP final exacta.

4. ¿Qué ocurre al obtener la IP?

Una vez que el ordenador recibe la dirección IP numérica, se establece una conexión directa mediante el protocolo TCP (y seguridad TLS/HTTPS). El navegador envía una petición HTTP al servidor remoto, el cual responde devolviendo el código HTML, imágenes y estilos que forman la página web.

5. Caché DNS y el TTL

Para no repetir todo el proceso de búsqueda cada vez que haces clic en un enlace, tu ordenador y los servidores intermedios guardan temporalmente los resultados en una Caché DNS. El TTL (Time To Live) es el tiempo en segundos que esa información se considera válida antes de volver a consultarse.

6. ¿Una o varias IPs por web?

Una página web moderna no suele tener una única IP. Debido al enorme tráfico, plataformas como YouTube o Amazon utilizan múltiples IPs y redes de distribución de contenido (CDN) repartidas por todo el mundo para balancear la carga y ofrecer la máxima velocidad según tu ubicación geográfica.

🚀 Publicación en GitHub Pages

Este sitio web ha sido diseñado en equipo y publicado de forma totalmente abierta utilizando GitHub Pages. Los pasos que hemos seguido para lograrlo son:

  1. Crear un repositorio público en GitHub con el código fuente en formato HTML y CSS.
  2. Acceder a la pestaña Settings (Configuración) del repositorio.
  3. Navegar hasta la sección Pages en el menú lateral.
  4. Seleccionar la rama principal (main / root) como origen de despliegue y guardar.
  5. Obtener el enlace web público generado automáticamente por GitHub para compartir el proyecto.
